# Continuous Integration Server


## How to clone the github repo
```bash
git clone https://github.com/Deadlica/continuous-integration.git
```

## How to run the CI server
To set up the server on Linux:
```bash
make setupLINUX
```

To set up the server on MAC:
```bash
make MAC
```

To compile, start the server and add a proxy using ngrok:
```bash
make run
```
